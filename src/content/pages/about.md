## 这个站点

一个用来放长文的地方。写代码写了些年头，零散的笔记散落在各种编辑器、聊天记录和 gist 里，最后都找不到了。所以有了这里：一个能长期维护、能按主题翻回去看的笔记本。

内容大致三类：

- **长文**：把一个问题的来龙去脉写清楚，通常是「为什么」多于「怎么做」。
- **笔记**：踩坑记录、配置片段、库的用法，短，但都是实际用过的。
- **代码**：Python 和 JavaScript 为主，高亮、行号、diff、可复制，尽量贴能直接跑的最小示例。

## 关于技术栈

站点是静态的：Astro 在构建时把 Markdown 渲染成 HTML，代码用 Shiki 在构建期着色，页面里没有运行时框架。好处是快，而且十年后 Markdown 文件还在，任何工具都能读。

文章本身放在 Git 仓库里，一篇一个文件，写完了提交就发布。图片跟着文章目录走，构建时自动压成 WebP/AVIF。

## 联系

有问题或者想讨论，欢迎开 issue 或发邮件。如果是文章里的代码跑不通，多半是我漏了某个前提条件，直接说就行。
